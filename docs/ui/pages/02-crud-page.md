# 通用增删改查页面

## 页面布局

主页面分为三部分：查询区域，操作区域和数据展示区域

二级页面：新增页面/编辑页面(没有特殊说明，复用新增页面即可)

### 查询区域

- 使用通用表单(查询)组件进行查询
- 根据查询接口入参列出的参数一一对应初始化查询控件
- 两个操作按钮：查询(`type=submit`)和重置

### 操作区域

- 新建：点击弹出[新增页面](#新增页面)
- 批量删除：默认 disabled,如果下方的表格选中了数据，则取消 disabled;
- 导入：可选，暂未实现，先不要添加
- 导出：必须有，按钮先加上，实现暂缓；

### 数据展示区域

- 显示**checkout**，操作区域的批量操作按钮(比如：批量删除)进行联动
- 最右侧有个**操作**列，防止两个按钮：编辑&删除
  - 编辑按钮：点击打开[编辑页面](#编辑页面)，并将对应主键设置为**禁止编辑**
  - 删除按钮：调用删除接口，删除当前数据
- 使用通用 table 组件
- 根据查询接口的出参确定展示字段
- 需要显示

### 新增页面

- 使用通用表单组件(编辑)

### 编辑页面

- 复用新增页面
- 注意主键需要设置为**禁止编辑**；
- 注意使用独立的[编辑接口](/docs/api/通用接口规范.md#更新编辑接口)进行提交
