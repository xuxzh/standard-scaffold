# 按钮图标映射

这个文档用于统一通用按钮语义与 `lucide` 图标映射，避免不同页面对同一操作使用不同图标。

## 使用原则

- 所有按钮默认都应搭配图标，除非界面空间、可访问性或已有成熟模式明确不适合。
- 同一语义在全局尽量复用同一个图标，不因页面差异随意更换。
- 新增按钮语义时，优先判断是否只是已有语义的别名；只有确实属于新语义时才新增映射。
- 如果一个按钮同时承担多个语义，以主动作语义选图标，不为兼顾全部含义叠加多个图标。

## 常用映射

- 新建：`circle-plus`
- 编辑：`square-pen`
- 删除：`trash`
- 返回：`chevron-left`
- 上一页：`chevron-left`
- 下一页：`chevron-right`
- 导入：`arrow-down-to-line`
- 导出：`arrow-up-from-line`
- 查询：`search`
- 重置：`rotate-ccw`
- 确认/提交：`check`
- 取消/关闭：`x`
- 重试：`rotate-cw`
- 预览：`eye`
- 登录：`log-in`
- 退出登录：`log-out`

## 维护约定

- 当某个按钮语义已经在多个页面重复出现时，应回写到这里，避免各处各自约定。
- 如果后续形成更细的分类，比如导航类、表单提交类、危险操作类，可继续在本文档内扩展，不回灌到总纲正文。
