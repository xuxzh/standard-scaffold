# 包装类型维护

这是一个标准的 CRUD 界面，参考[crud 文档](/docs/ui/README.md)，视觉与交互参考同目录 `assets/` 中的页面截图。

参考页面：`https://ztmymzd7np.coze.site/admin/packaging/type`

接口文档：[`api.md`](./api.md)

## 页面范围

用于维护包装类型主数据。包装类型描述包装容器或包装材料的大类，并标识该类型是否属于循环包装。

页面采用“查询区 + 列表区 + 新增/编辑弹窗”的结构：

- 顶部查询区：按类型编码、类型名称、循环包装状态筛选。
- 列表工具栏：新增、批量删除、刷新、列设置、导入、导出。
- 数据表格：展示包装类型数据，支持勾选、分页、单行编辑和删除。
- 新增/编辑弹窗：维护类型编码、类型名称、循环包装和描述。

## 查询区

查询区位于列表上方，使用一行表单布局；窄屏时按现有表单规则自动换行。

| 控件 | 类型 | 绑定字段 | 说明 |
| ---- | ---- | -------- | ---- |
| 类型编码 | 文本输入 | `TypeCode` | 支持模糊查询 |
| 类型名称 | 文本输入 | `TypeName` | 支持模糊查询 |
| 循环包装 | 下拉选择 | `IsRecyclable` | 选项：全部、是、否 |

操作按钮：

- 查询：按当前条件调用 `GetPackagingTypeAutoQueryDatas`。
- 重置：清空查询条件并回到第一页重新查询。

## 列表区

工具栏左侧放置主要操作：

- 新增类型：打开新增弹窗。
- 批量删除：未选择数据时禁用；选择一条或多条后启用。

工具栏右侧放置辅助操作：

- 刷新：保留当前查询条件重新加载列表。
- 列设置：控制表格列显隐。
- 导入、导出：保持与参考页面一致的占位能力。

表格列：

| 列 | 说明 |
| -- | ---- |
| 勾选 | 支持批量删除 |
| 序号 | 当前页行号 |
| 类型编码 | `TypeCode` |
| 类型名称 | `TypeName` |
| 循环包装 | `IsRecyclable`，显示为是/否 |
| 描述 | `Description` |
| 操作 | 编辑、删除 |

分页沿用参考页面：左侧显示总条数，右侧显示每页条数、页码和上一页/下一页。

## 新增/编辑弹窗

弹窗标题按操作显示为“新增类型”或“编辑类型”。弹窗底部按钮为返回、重置、确认。

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 类型编码 | 文本输入 | 是 | 新增时可编辑；编辑时建议只读 |
| 类型名称 | 文本输入 | 是 | 包装类型展示名称 |
| 循环包装 | 开关 | 是 | 默认关闭 |
| 描述 | 文本输入 | 否 | 简短说明 |

基础校验：

- 类型编码、类型名称不能为空。
- 类型编码提交前去除首尾空格。
- 编辑时仅提交 `NeedUpdateFields`，包含 `Id` 和发生变化的字段。

## 状态与反馈

- 查询 loading 时禁用查询按钮并显示表格加载态。
- 新增/编辑提交成功后关闭弹窗，刷新当前列表。
- 删除和批量删除前展示确认提示，确认后传入业务 DTO 对象，不只传 `Id`。
- 查询无数据时展示空状态，不弹错误提示。
- 后端返回保存或删除错误时保留当前页面状态，并展示错误消息。
