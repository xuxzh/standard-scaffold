# 包装套包维护

这是一个标准的 CRUD 界面，参考[crud 文档](/docs/ui/README.md)，视觉与交互参考同目录 `assets/` 中的页面截图，并与 `packaging-type/assets` 的基础 CRUD 风格保持一致。

参考页面：`https://ztmymzd7np.coze.site/admin/packaging/kit`

接口文档：[`api.md`](./api.md)

## 页面范围

用于维护包装套包主数据及其子件列表。套包由一个主件物料和多个子件组成，子件列表以数组形式随套包一并保存。

页面采用“查询区 + 列表 + 新增/编辑弹窗 + 子件选择弹窗”的结构。

## 查询区

| 控件 | 类型 | 绑定字段 | 说明 |
| ---- | ---- | -------- | ---- |
| 套包编码 | 文本输入 | `KitCode` | 支持模糊查询 |
| 套包名称 | 文本输入 | `KitName` | 支持模糊查询 |

操作按钮：

- 查询：按当前条件调用 `GetPackagingKitAutoQueryDatas`。
- 重置：清空查询条件并回到第一页重新查询。

## 列表区

工具栏：

- 新增套包：打开新增弹窗。
- 批量删除：未选择数据时禁用。
- 刷新、列设置、导入、导出：沿用包装类型维护。

表格列：

| 列 | 说明 |
| -- | ---- |
| 勾选 | 支持批量删除 |
| 序号 | 当前页行号 |
| 套包编码 | `KitCode` |
| 套包名称 | `KitName` |
| 主件物料编码 | `MainMaterialCode` |
| 主件物料名称 | `MainMaterialName` |
| 单位 | `Unit` |
| 虚拟主件 | `IsVirtualMain`，显示为是/否 |
| 子件数 | `ChildCount`，显示为“n 项” |
| 操作 | 查看子件、编辑、删除 |

子件数旁可提供查看入口，点击后展开当前套包的子件明细或打开只读明细弹窗。

## 新增/编辑弹窗

弹窗标题按操作显示为“新增套包”或“编辑套包”。底部按钮为返回、重置、确认。

### 主信息

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 套包编码 | 文本输入 | 是 | 新增时可编辑；编辑时建议只读 |
| 套包名称 | 文本输入 | 是 | 套包展示名称 |
| 主件物料编码 | 选择输入 | 是 | 点击选择物料，选择后带出物料名称 |
| 主件物料名称 | 文本输入 | 是 | 自动带出，只读 |
| 单位 | 下拉选择 | 是 | 默认“套” |
| 虚拟主件 | 开关 | 是 | 默认关闭 |
| 备注 | 文本输入 | 否 | 可选 |

### 子件列表

主信息下方展示子件明细表。

| 列 | 说明 |
| -- | ---- |
| 子件编码 | `Children[].Code` |
| 子件名称 | `Children[].Name` |
| 数量 | `Children[].Quantity`，正整数 |
| 单位 | `Children[].Unit` |
| 操作 | 删除 |

操作：

- 添加子件：打开物料选择弹窗。
- 删除子件：从当前弹窗内移除该行，不立即调用删除接口。

## 子件选择弹窗

添加子件时打开二级弹窗：

- 查询条件：物料编码、物料名称。
- 列表支持多选。
- 底部显示“已选 n 项”。
- 未选择数据时确认按钮禁用。
- 确认后将选择的物料追加到子件列表，默认数量为 1，单位使用物料单位或默认单位。

## 状态与反馈

- `ChildCount` 由后端根据 `Children` 自动计算，前端不提交该字段。
- 编辑时 `Children` 作为整体明细维护；确认后随主表字段一起提交。
- 新增/编辑提交前校验主件物料和子件编码不能重复。
- 删除和批量删除前展示确认提示，确认后传入业务 DTO 对象。
