# 包装层级维护

这是一个标准的 CRUD 界面，参考[crud 文档](/docs/ui/README.md)，视觉与交互参考同目录 `assets/` 中的页面截图，并与 `packaging-type/assets` 的基础 CRUD 风格保持一致。

参考页面：`https://ztmymzd7np.coze.site/admin/packaging/hierarchy`

接口文档：[`api.md`](./api.md)

## 页面范围

用于维护包装层级主数据，并提供层级关系图查看能力。层级序号从 1 开始，序号越大表示越外层；父层层级只能选择序号小于当前层级的层级。

页面沿用包装类型维护的整体结构：

- 顶部查询区：输入查询条件，执行查询和重置。
- 列表工具栏：新增、批量删除、刷新、列设置、查看关系图、导入、导出。
- 数据表格：展示层级主数据，支持勾选、分页、单行编辑和删除。
- 新增/编辑弹窗：维护层级基础字段。
- 关系图弹窗：以树形关系展示层级嵌套结构。

## 查询区

查询区位于列表上方，使用一行表单布局；窄屏时按现有表单规则自动换行。

| 控件         | 类型     | 绑定字段          | 说明                     |
| ------------ | -------- | ----------------- | ------------------------ |
| 层级编码     | 文本输入 | `LevelCode`       | 支持模糊查询             |
| 层级名称     | 文本输入 | `LevelName`       | 支持模糊查询             |
| 父层层级编码 | 下拉选择 | `ParentLevelCode` | 可为空，选择已有层级编码 |

操作按钮：

- 查询：按当前条件调用 `GetPackagingLevelAutoQueryDatas`。
- 重置：清空查询条件并回到第一页重新查询。

## 列表区

工具栏左侧放置主要操作：

- 新增层级：打开新增弹窗。
- 批量删除：未选择数据时禁用；选择一条或多条后启用。

工具栏右侧放置辅助操作：

- 刷新：保留当前查询条件重新加载列表。
- 列设置：控制表格列显隐。
- 查看关系图：打开关系图弹窗，调用 `GetPackagingLevelTree`。
- 导入、导出：保持与包装类型维护一致的占位能力。

表格列：

| 列           | 说明                              |
| ------------ | --------------------------------- |
| 勾选         | 支持批量删除                      |
| 序号         | 当前页行号                        |
| 层级编码     | `LevelCode`                       |
| 层级序号     | `LevelSequence`                   |
| 层级名称     | `LevelName`                       |
| 父层层级编码 | `ParentLevelCode`，为空时显示 `-` |
| 父级层级名称 | `ParentLevelName`，为空时显示 `-` |
| 描述         | `Description`                     |
| 操作         | 编辑、删除                        |

分页沿用包装类型维护：左侧显示总条数，右侧显示每页条数、页码和上一页/下一页。

## 新增/编辑弹窗

弹窗标题按操作显示为“新增层级”或“编辑层级”。底部按钮为返回、重置、确认。

| 字段         | 类型     | 必填 | 说明                                                      |
| ------------ | -------- | ---- | --------------------------------------------------------- |
| 层级编码     | 文本输入 | 是   | 新增时可编辑；编辑时建议只读                              |
| 层级序号     | 数字输入 | 是   | 最小值为 1                                                |
| 层级名称     | 文本输入 | 是   | 层级展示名称                                              |
| 父层层级编码 | 下拉选择 | 否   | 层级序号为 1 时不可填；候选项只展示序号小于当前层级的层级 |
| 父级层级名称 | 文本输入 | 否   | 根据父层层级编码自动带出，只读                            |
| 描述         | 文本输入 | 否   | 简短说明                                                  |

基础校验：

- 层级编码、层级序号、层级名称不能为空。
- 层级序号必须大于等于 1。
- 层级序号等于 1 时，父层层级编码必须为空。
- 选择父层层级后，父层层级序号必须小于当前层级序号。

## 关系图弹窗

点击“查看关系图”后打开弹窗，展示当前公司/工厂下的包装层级树。

- 根节点为无父层层级的数据，通常是序号最小的层级。
- 节点展示层级名称和层级编码。
- 子节点来自 `Children`，按层级序号升序展示。
- 无数据时显示空状态，不弹错误提示。
- 关系图只读，不提供拖拽改层级能力。

## 状态与反馈

- 查询 loading 时禁用查询按钮并显示表格加载态。
- 新增/编辑提交成功后关闭弹窗，刷新当前列表。
- 删除和批量删除前展示确认提示，确认后传入业务 DTO 对象。
- 后端返回层级校验错误时，在弹窗内保留用户输入并展示错误消息。
