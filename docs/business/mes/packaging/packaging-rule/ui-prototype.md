# 包装规则维护

这是一个标准的 CRUD 界面，参考[crud 文档](/docs/ui/README.md)，视觉与交互参考同目录 `assets/` 中的页面截图，并与 `packaging-type/assets` 的基础 CRUD 风格保持一致。

参考页面：`https://ztmymzd7np.coze.site/admin/packaging/material-relation`

接口文档：[`api.md`](./api.md)

## 页面范围

用于维护包装规则主数据、包装关系明细和规则配置。包装规则决定包装层级、规格、数量、包装方式，以及混箱、标签打印、封箱触发和异常处理策略。

页面采用“查询区 + 规则列表 + 新增/编辑弹窗 + 规则配置弹窗”的结构。

## 查询区

| 控件 | 类型 | 绑定字段 | 说明 |
| ---- | ---- | -------- | ---- |
| 规则编码 | 文本输入 | `RuleCode` | 支持模糊查询 |
| 规则名称 | 文本输入 | `RuleName` | 支持模糊查询 |
| 默认 | 下拉选择 | `IsDefault` | 选项：全部、是、否 |
| 状态 | 下拉选择 | `IsEnabled` | 选项：全部、启用、禁用 |

操作按钮：

- 查询：按当前条件调用 `GetPackagingRuleAutoQueryDatas`。
- 重置：清空查询条件并回到第一页重新查询。
- 查询条件较多时可保留“展开/收起”入口。

## 列表区

工具栏：

- 新增规则：打开新增弹窗。
- 批量删除：未选择数据时禁用。
- 刷新、列设置：沿用包装类型维护。

表格列：

| 列 | 说明 |
| -- | ---- |
| 勾选 | 支持批量删除 |
| 序号 | 当前页行号 |
| 规则编码 | `RuleCode` |
| 规则名称 | `RuleName` |
| 默认 | `IsDefault`，显示为是/否 |
| 状态 | `IsEnabled`，显示为启用/禁用 |
| 操作 | 配置规则、编辑、删除 |

“配置规则”打开规则配置弹窗；编辑只维护规则主信息和包装关系明细。

## 新增/编辑弹窗

弹窗标题按操作显示为“新增规则”或“编辑规则”。底部按钮为返回、重置、确认。

### 主信息

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 规则编码 | 文本输入 | 是 | 新增时可编辑；编辑时建议只读 |
| 规则名称 | 文本输入 | 是 | 规则展示名称 |
| 默认 | 开关 | 是 | 是否默认规则 |
| 状态 | 开关 | 是 | 是否启用 |
| 备注 | 文本输入 | 否 | 可选 |

### 包装关系明细

主信息下方展示包装关系明细表，点击“添加包装”新增一行。

| 列 | 类型 | 绑定字段 | 说明 |
| -- | ---- | -------- | ---- |
| 层级序号 | 数字输入 | `Details[].LevelSequence` | 可由层级编码带出 |
| 层级编码 | 选择输入 | `Details[].PackagingLevelCode` | 必填，选择后带出层级名称和序号 |
| 规格编码 | 选择输入 | `Details[].SpecCode` | 必填，选择后带出规格名称、单位、包装类型 |
| 标准包装数量 | 数字输入 | `Details[].StandardQuantity` | 必填，正整数 |
| 最大包装数量 | 数字输入 | `Details[].MaxQuantity` | 必填，正整数，不能小于标准包装数量 |
| 包装方式 | 下拉选择 | `Details[].PackagingMethod` | 必填，例如自动、手动 |
| 操作 | 按钮 | - | 删除该明细行 |

后端会根据层级编码和规格编码自动校验并填充名称类字段。前端仍应在选择器中尽量带出展示值，降低录入错误。

## 规则配置弹窗

点击列表行的“配置规则”打开。弹窗顶部保留当前规则编码和规则名称的只读信息，主体使用页签组织四类配置。

### 混箱规则

- 禁止不同产品混箱
- 禁止不同批次混箱
- 禁止不同工单混箱
- 禁止不同生产任务混箱
- 禁止跨质量状态混箱

提供“一键全选”和“一键清空”按钮。

### 标签打印规则

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 重复打印次数上限 | 数字输入 | `LabelPrintRule.ReprintLimit` |
| 默认标签模板名称 | 选择输入 | `LabelPrintRule.DefaultTemplate` |

### 封箱触发规则

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 超时未封箱预警（分钟） | 数字输入 | `SealingRule.TimeoutAlert` |
| 工单完成自动封箱 | 开关 | `SealingRule.AutoSealOnWorkOrderComplete` |
| 任务完成自动封箱 | 开关 | `SealingRule.AutoSealOnTaskComplete` |
| 满箱自动封箱 | 开关 | `SealingRule.AutoSealOnFullBox` |

### 异常处理规则

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 周转工具强制清空 | 开关 | `ExceptionRule.ForceClearOnCycleTool` |

配置弹窗底部按钮为重置、确认。确认时调用 `StorePackagingRuleConfigData`，按规则编码全量覆盖配置。

## 状态与反馈

- 新增/编辑提交前校验规则编码、规则名称和明细必填项。
- 包装关系明细为空时允许保存主表，但应给出弱提示，提醒该规则暂无包装明细。
- 删除规则前展示确认提示，并提示会一并删除关联明细。
- 配置保存成功后关闭配置弹窗，不强制刷新列表。
