# 物料包装关系维护

这是一个标准的 CRUD 界面，参考[crud 文档](/docs/ui/README.md)，视觉与交互参考同目录 `assets/` 中的页面截图，并与 `packaging-type/assets` 的基础 CRUD 风格保持一致。

参考页面：`https://ztmymzd7np.coze.site/admin/packaging/material-packaging`

接口文档：[`api.md`](./api.md)

## 页面范围

用于维护物料与包装规则之间的关联关系。每条关系以物料编码和包装规则编码作为唯一标识，并携带包装关系明细。参考页面左侧提供物料快速筛选，右侧展示所选物料或筛选条件下的包装关系明细。

页面采用“物料筛选侧栏 + 查询区 + 明细列表 + 新增/编辑弹窗”的结构。

## 物料筛选侧栏

左侧侧栏用于快速定位物料：

- 顶部提供“搜索物料名称/编码”输入框。
- 下方列表展示物料编码和物料名称。
- 点击物料后，右侧查询区自动带入物料条件并刷新列表。
- 未选择物料时，右侧按查询条件展示全部关系。

## 查询区

右侧查询区默认展示常用筛选条件：

| 控件 | 类型 | 绑定字段 | 说明 |
| ---- | ---- | -------- | ---- |
| 规则编码 | 文本输入 | `PackagingRuleCode` | 支持模糊查询 |
| 包装层级 | 文本输入 | `Details[].PackagingLevelName` | 用于前端展示筛选；接口不支持时可作为本地筛选或后续扩展 |
| 包装规格 | 文本输入 | `Details[].SpecName` | 用于前端展示筛选；接口不支持时可作为本地筛选或后续扩展 |
| 包装类型 | 文本输入 | `Details[].PackagingTypeName` | 用于前端展示筛选；接口不支持时可作为本地筛选或后续扩展 |

接口查询字段以 `MaterialCode`、`MaterialName`、`PackagingRuleCode`、`PackagingRuleName` 为准。页面上的层级、规格、类型筛选如果后端暂不支持，应在实现时明确为前端本地过滤或隐藏。

操作按钮：

- 查询：按当前条件调用 `GetMaterialPackagingRelationAutoQueryDatas`。
- 重置：清空查询条件、取消左侧物料选中并回到第一页重新查询。

## 列表区

工具栏：

- 新增：打开新增弹窗。
- 批量删除：未选择数据时禁用。
- 刷新、列设置、导入、导出：沿用包装类型维护。

参考页面将包装关系明细展开为表格行展示，列如下：

| 列 | 说明 |
| -- | ---- |
| 勾选 | 支持批量删除 |
| 序号 | 当前页行号 |
| 包装规则编码 | `PackagingRuleCode` |
| 规则名称 | `PackagingRuleName` |
| 层级序号 | `Details[].LevelSequence` |
| 包装层级编码 | `Details[].PackagingLevelCode` |
| 包装层级 | `Details[].PackagingLevelName` |
| 包装规格 | `Details[].SpecName` |
| 包装规格编码 | `Details[].SpecCode` |
| 包装数量 | `Details[].Quantity` |
| 单位 | `Details[].Unit` |
| 箱标签打印模版 | `Details[].BoxLabelPrintTemplate` |
| 装箱单打印模板 | `Details[].PackingListPrintTemplate` |
| 备注 | `Remark` |
| 包装类型 | `Details[].PackagingTypeName` |
| 操作 | 编辑、删除 |

实现时可以保留接口返回的“关系主表”为数据源，在表格层将 `Details` 展平展示；编辑和删除仍以关系主表记录为单位。

## 新增/编辑弹窗

弹窗标题按操作显示为“新增物料包装关系”或“编辑物料包装关系”。底部按钮为返回、重置、确认。

### 主信息

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 物料编码 | 选择输入 | 是 | 点击选择物料，选择后带出物料名称 |
| 物料名称 | 文本输入 | 是 | 自动带出，只读 |
| 包装规则编码 | 选择输入 | 是 | 点击选择包装规则，选择后带出规则名称和规则明细 |
| 规则名称 | 文本输入 | 是 | 自动带出，只读 |
| 备注 | 文本输入 | 否 | 可选 |

### 包装关系明细

选择包装规则后，弹窗内展示该规则对应的包装关系明细，允许按物料包装关系要求补充或调整标签模板字段。

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 层级序号 | 数字/只读 | 是 | `LevelSequence` |
| 包装层级编码 | 文本/只读 | 是 | `PackagingLevelCode` |
| 包装层级名称 | 文本/只读 | 是 | `PackagingLevelName` |
| 包装规格编码 | 文本/只读 | 是 | `SpecCode` |
| 包装规格名称 | 文本/只读 | 是 | `SpecName` |
| 包装数量 | 数字输入 | 是 | `Quantity`，正整数 |
| 单位 | 文本/下拉 | 是 | `Unit` |
| 包装类型名称 | 文本/只读 | 是 | `PackagingTypeName` |
| 箱标签打印模板 | 选择输入 | 否 | `BoxLabelPrintTemplate` |
| 装箱单打印模板 | 选择输入 | 否 | `PackingListPrintTemplate` |

## 状态与反馈

- 新增时必须选择物料和包装规则。
- 物料编码 + 包装规则编码组合唯一；后端返回重复错误时保留弹窗输入并展示错误消息。
- 明细由前端直接传入，前端必须保证编码、名称、数量、单位和模板字段准确。
- 编辑时如果提交 `Details`，按接口约定全量覆盖明细列表。
- 删除和批量删除前展示确认提示，确认后传入业务 DTO 对象。
