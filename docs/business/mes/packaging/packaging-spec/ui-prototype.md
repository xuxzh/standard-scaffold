# 包装规格维护

这是一个标准的 CRUD 界面，参考[crud 文档](/docs/ui/README.md)，视觉与交互参考同目录 `assets/` 中的页面截图，并与 `packaging-type/assets` 的基础 CRUD 风格保持一致。

参考页面：`https://ztmymzd7np.coze.site/admin/packaging/specification`

接口文档：[`api.md`](./api.md)

## 页面范围

用于维护包装规格主数据。包装规格关联包装类型、包装层级和条码规则，并记录尺寸、重量、容量、堆叠和启用状态等信息。

页面采用“查询区 + 宽表列表 + 新增/编辑弹窗”的结构。由于字段较多，列表应支持横向滚动，操作列固定在右侧。

## 查询区

查询区默认展示常用筛选条件：

| 控件 | 类型 | 绑定字段 | 说明 |
| ---- | ---- | -------- | ---- |
| 规格编码 | 文本输入 | `SpecCode` | 支持模糊查询 |
| 规格名称 | 文本输入 | `SpecName` | 支持模糊查询 |
| 包装类型编码 | 文本输入 | `PackagingTypeCode` | 支持按类型过滤 |
| 启用 | 下拉选择 | `IsEnabled` | 选项：全部、启用、禁用 |

操作按钮：

- 查询：按当前条件调用 `GetPackagingSpecAutoQueryDatas`。
- 重置：清空查询条件并回到第一页重新查询。

## 列表区

工具栏：

- 新增规格：打开新增弹窗。
- 批量删除：未选择数据时禁用。
- 刷新、列设置、导入、导出：沿用包装类型维护。

表格列：

| 列 | 说明 |
| -- | ---- |
| 勾选 | 支持批量删除 |
| 序号 | 当前页行号 |
| 规格编码 | `SpecCode` |
| 规格名称 | `SpecName` |
| 包装类型编码 | `PackagingTypeCode` |
| 包装类型 | `PackagingTypeName` |
| 包装层级编码 | `PackagingLevelCode` |
| 包装层级 | `PackagingLevelName` |
| 条码规则编码 | `BarcodeRuleCode` |
| 条码规则 | `BarcodeRuleName` |
| 长(cm) | `Length` |
| 宽(cm) | `Width` |
| 高(cm) | `Height` |
| 最大承重(kg) | `MaxWeight` |
| 毛重(kg) | `GrossWeight` |
| 皮重(kg) | `TareWeight` |
| 体积(m³) | `Volume` |
| 标准容量 | `StandardCapacity` |
| 单位 | `Unit` |
| 堆叠上限 | `StackLimit` |
| 启用 | `IsEnabled`，显示为启用/禁用状态 |
| 操作 | 编辑、删除 |

## 新增/编辑弹窗

弹窗标题按操作显示为“新增规格”或“编辑规格”。字段较多，采用两列或分组表单布局；窄屏时单列展示。

### 基础信息

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 规格编码 | 文本输入 | 是 | 新增时可编辑；编辑时建议只读 |
| 规格名称 | 文本输入 | 是 | 规格展示名称 |
| 包装类型编码 | 下拉选择 | 是 | 选择包装类型后自动带出名称 |
| 包装类型名称 | 文本输入 | 是 | 自动带出，只读 |
| 包装层级编码 | 下拉选择 | 是 | 选择包装层级后自动带出名称 |
| 包装层级名称 | 文本输入 | 是 | 自动带出，只读 |
| 条码规则编码 | 选择输入 | 是 | 点击选择条码规则 |
| 条码规则名称 | 文本输入 | 是 | 自动带出，只读 |

### 尺寸重量

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 长(cm) | 数字输入 | 是 | 支持小数 |
| 宽(cm) | 数字输入 | 是 | 支持小数 |
| 高(cm) | 数字输入 | 是 | 支持小数 |
| 体积(m³) | 数字输入 | 是 | 可由长宽高换算后允许人工调整 |
| 最大承重(kg) | 数字输入 | 是 | 支持小数 |
| 毛重(kg) | 数字输入 | 是 | 支持小数 |
| 皮重(kg) | 数字输入 | 是 | 支持小数 |

### 容量状态

| 字段 | 类型 | 必填 | 说明 |
| ---- | ---- | ---- | ---- |
| 标准容量 | 数字输入 | 是 | 正整数 |
| 单位 | 下拉选择 | 是 | 与业务单位保持一致 |
| 堆叠上限 | 数字输入 | 是 | 正整数 |
| 启用 | 开关 | 是 | 默认启用 |
| 备注 | 文本输入 | 否 | 可选 |

底部按钮为返回、重置、确认。

## 状态与反馈

- 表格字段较多时，保持列头和操作列可见，避免编辑入口被横向滚动遮挡。
- 新增/编辑提交前校验必填字段和数字字段范围。
- 删除和批量删除前展示确认提示，确认后传入业务 DTO 对象。
- 提交成功后关闭弹窗并刷新当前页。
